# CampusEats Brief

## What the system does
CampusEats is a campus food ordering platform where students can browse menus, place orders, pay, and track pickup/delivery from campus dining providers.

## Who uses it
- Students
- Restaurant/cafeteria staff
- Delivery runners (if delivery mode exists)
- Admin/operations team

## Nouns (things/services)
- User
- Student Profile
- Restaurant
- Menu
- Menu Item
- Cart
- Order
- Payment
- Address / Pickup Point
- Delivery Assignment
- Notification
- Review / Rating
- Promo / Coupon

## Verbs (actions/tasks/contracts)
- Sign up / Log in
- Browse restaurants
- Search/filter menu items
- Add/remove cart items
- Place order
- Pay for order
- Accept/reject order (restaurant)
- Prepare order
- Assign delivery / mark ready for pickup
- Track order status
- Notify user
- Cancel/refund order
- Rate/review order
